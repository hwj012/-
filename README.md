# 一炉三享 · 香，正在被重新编译

多功能电子香炉的沉浸式数字互动装置原型。将熏香、煮茶、温茶三种使用方式转化为可操作的视觉体验。

## 主要体验
- 熏香、煮茶、温茶模式切换
- 温度滑块与 +/- 调整、定时选择、电源状态和重置
- 动态 SVG 香炉示意、发热盘状态和上升蒸汽
- 茶叶、花草、香木的植物/香材标本交互
- 顶盖、滤网、香材仓、陶瓷炉体、PTC 发热盘、MCU、胡桃木底座结构拆解
- 放料、触控、享受三步仪式流程
- 响应式布局、键盘焦点样式和 reduced-motion 支持

## 本地运行
需要 Node.js 与 npm：

```bash
npm install
npm run dev
```

技术栈：TanStack Start、React、TypeScript、Tailwind CSS v4。
